# Vorfälle

Berichte von Agenten über Stellen, an denen merge-train sie in die Irre geführt hat (Meldung, Skill, CLI).

| Ort | Inhalt |
|---|---|
| `vorfaelle/` (Repo-Wurzel, gitignored) | **neu**: Eingang, noch nicht abgearbeitet. Agenten legen hier `JJJJ-MM-TT-<thema>.md` ab. |
| `docs/vorfaelle/` (hier) | **abgearbeitet**: Archiv. Jeder Bericht beginnt mit einem Block „Umgesetzt“ (was geändert wurde, Commit, bewusst nicht Umgesetztes). |

Abarbeiten: Bericht lesen, beheben, den Block „Umgesetzt“ unter den Titel setzen und die Datei hierher verschieben.
Der Bericht selbst bleibt, wie der Agent ihn geschrieben hat.
